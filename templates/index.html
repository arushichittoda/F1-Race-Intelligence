THE PROJECT

Formula 1 Race Intelligence

This project provides a visual exploration of Formula 1 racing data from multiple seasons. The analysis focuses on driver performance, team performance, championship progression, tyre strategies, circuit participation and podium achievements.

Interactive Tableau visualizations are integrated into this Flask web application, allowing users to explore Formula 1 insights directly through a web browser.
