# Formula 1 Race Intelligence

A Flask-based web application integrating an interactive Formula 1 Race Intelligence Dashboard and Story created using Tableau Public.

## Project Overview

This project combines Tableau Public visualizations with a Flask web application to provide an interactive and accessible Formula 1 analysis platform.

The website allows users to explore:

- Formula 1 Race Intelligence Dashboard
- Interactive Tableau Story
- Driver performance
- Team performance
- Championship analysis
- Tyre compound usage
- Race participation
- Podium achievements

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Tableau Public

## Tableau Integration

The Tableau Dashboard and Story are embedded directly into the Flask website using Tableau Public URLs.
